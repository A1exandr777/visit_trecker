# 📊 Расширенный счётчик посещений на aiohttp с GeoIP, браузерами и временной аналитикой

Веб-сервис на [aiohttp](https://docs.aiohttp.org/), который собирает подробную аналитику посещений сайта и сохраняет данные в локальный файл `visits.json` — **без базы данных**.

Сервис собирает статистику по IP, браузерам, странам, регионам, месяцам, дням недели и часам суток.

---

## Возможности

### 📌 Базовая статистика

* Общее количество визитов
* Статистика по:

  * дням (`YYYY-MM-DD`)
  * месяцам (`YYYY-MM`)
  * годам (`YYYY`)

### 👤 Уникальные посетители (по IP)

* Общая уникальность
* Уникальные посетители по дням / месяцам / годам
* Хранение списка всех уникальных IP

### 🌍 Гео-аналитика (GeoLite2)

* Подсчёт посещений по **странам**
* Подсчёт посещений по **регионам**
* Автоматическое определение страны/региона через MaxMind GeoLite2

> Для геолокации требуется база `GeoLite2-City.mmdb` (см. ниже).

### 🧭 Браузеры

* Определение браузера через `user_agents`
* Подсчёт количества визитов по каждому браузеру

### 🕒 Временная аналитика

* Посещаемость по **месяцам (January, February…)**
* Посещаемость по **дням недели (Monday, Tuesday…)**
* Посещаемость по **часам суток (00–23)**

### 🖥 HTML-дашборд

* Красивый HTML интерфейс с:

  * Топ браузеров
  * Топ стран
  * Активностью по часам
  * Сезонностью по месяцам
  * Статистикой по дням недели

### 🧩 API

* `/count` — полный JSON-дамп статистики
* `/reset` — сброс статистики

---

## 🧰 Требования

* Python **3.8+**
* `aiohttp`
* `user-agents`
* `geoip2`

Установка зависимостей:

```bash
pip install aiohttp user-agents geoip2
```

### 📌 Добавление GeoLite2 базы

Скачайте бесплатную базу:

[https://dev.maxmind.com/geoip/geolite2-free-geolocation-data](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data)

И положите файл рядом с `main.py`:

```
GeoLite2-City.mmdb
```

---

## 🚀 Запуск

```bash
python main.py
```

Сервис поднимется на:

```
http://0.0.0.0:8080
```

---

## 🌐 Эндпоинты

| Метод | Путь     | Описание                         |
| ----- | -------- | -------------------------------- |
| GET   | `/`      | HTML-дашборд со всеми графами    |
| GET   | `/count` | JSON со всеми собранными данными |
| POST  | `/reset` | Полный сброс статистики          |

## 🔄 Сброс статистики

```bash
curl -X POST http://localhost:8080/reset
```

Ответ:

```json
{"status": "ok", "message": "counters reset"}
```
